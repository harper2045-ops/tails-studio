Tails Of History Studio Tools

Tails Of History Studio Tools is a private, internal publishing tool used only by the owner of the YouTube channel Tails Of History Official.

It runs on the owner's own computer and uses the YouTube Data API and YouTube Analytics API to:

  • upload finished Shorts to the owner's own channel, with the correct title, description, tags, AI-content disclosure and audience settings;
  • schedule those uploads;
  • read the channel's own performance statistics so the owner can improve future videos.

The tool is not offered to the public and does not access any other user's account or data.
